## Methodology

- **Stack base:** Astro · Next.js · SvelteKit · TypeScript · Tailwind · Supabase · Netlify · Cloudflare · Resend · PostHog
- **Delivery:** First version live within 48 hours · Fast pris · Customer owns the GitHub repo
- **Operations:** Search Console · GA4 · PostHog · scheduled remote routines for health, SEO, links
